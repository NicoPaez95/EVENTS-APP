# ⚙️ Events App API

Backend service for the Events App built with Node.js and Express.

## 🏗️ Architecture: Controllers & Routes Pattern
This project follows a modular structure to separate routing logic from business logic:

- **Routes**: Define the endpoints and HTTP methods.
- **Controllers**: Handle the request logic, data processing, and responses.
- **Models**: Manage data structures and error handling.

## 🚀 Getting Started
1. `npm install`
2. `npm run dev` (Starts server with Nodemon at http://localhost:5000)
